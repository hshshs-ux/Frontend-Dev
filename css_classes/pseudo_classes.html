Examples of :hover, :focus, :active, and :nth-child()

:hover

Hover over the button to see the background color change.

:focus

Click or tab into the input box to see the border color change.

:active

Press and hold the button to see the color change while active.

Alternate background colors are applied to list items using nth-child.
